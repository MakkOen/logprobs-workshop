# "Old" ML vs. Modern AI

::::{grid} 2
:::{grid-item-card} Old ML
- Gather large amounts of labeled data
- Design and experiment with model architectures
- Build train / eval / production pipelines
- Train and host your own models

**Slow. Expensive. But yours.**
:::
:::{grid-item-card} Modern AI
- Write a prompt
- Call an API (model lives elsewhere)
- Minimal data needed, mostly for evaluation

**Fast. Cheap. But a black box you pray to.**
:::
::::

---

How do you keep the speed of modern AI while regaining at least some of the control from traditional ML?

:::{admonition} The good news
:class: tip
You don't need anything new. You just need to remember the basics and realise they still apply, even with black-box LLMs.
:::
