# LLM Confidence & Logprobs Workshop

Welcome to the Logprobs Workshop by Luděk Matyska, ROUVY and Vojtech Kadlec, STRV.

## [https://tinyurl.com/logprobs-workshop](https://tinyurl.com/logprobs-workshop)

This workshop will teach you how to use logprobs (log probabilities) from LLMs to build confidence scores, improve classification pipelines, and detect hallucinations in structured outputs.
